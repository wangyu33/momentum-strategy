# 07 国内 ETF 防守保守版策略

## 1. 目标

这份模板是在 `06_domestic_etf_defensive_basic_strategy` 基础上进一步保守化，主要针对下面三类需求：

1. 希望继续保留国内 ETF 轮动框架，但不接受过高换手。
2. 希望在弱市里更早地引入债券与现金替代。
3. 希望把防守从“黄金/红利低波/商品承接”进一步升级为“政金债 + 国债 + 现金替代”的组合防守。

所以它的关键词是：

- **更早防守**
- **更慢调仓**
- **更多债券/现金替代**

---

## 2. 相比基础版，保守版做了哪些变化

### 2.1 加入 `511580` 政金债 ETF

基础版的常规防守池主要是：

- `518880` 黄金ETF
- `512890` 红利低波ETF
- `159985` 豆粕ETF

保守版新增：

- `511580` 政金债ETF

这样做的意义是：

- 当权益转弱但还没到极端风险时，防守资产里就已经有更明确的债券承接选项。
- 比“只在极弱市才切 511260”更早把组合久期和风险降下来。

### 2.2 加入“现金替代”

保守版不再假设所有剩余权重都必须继续满配到某个 ETF，而是显式允许：

- 把一部分仓位停在 **现金替代**

回测脚本里用的是合成 `CASH` 资产（零收益占位），用于表达：

- 弱趋势时主动降低总暴露
- 过热或极弱市里，不强迫所有资金都重新分配给风险资产或长久期资产

这更贴近保守账户的真实需求。

### 2.3 改为周频调仓

基础版是：

- 日频更新信号
- 有变化就调仓

保守版改为：

- **周频调仓**（每周最后一个交易日更新并执行）

这样做的好处：

- 降低噪音交易
- 减少短期假突破造成的来回切换
- 更适合中低频、防守优先的资金

### 2.4 更早压仓

保守版把几项关键参数都提前：

- 更高的绝对动量门槛
- 更早触发弱市过滤
- 更小的 top2 接近容忍度
- 更早启用过热降仓

也就是说：

- 同样一段市场，保守版会比基础版更早从“进攻”转向“防守”

---

## 3. 保守版策略结构

一句话概括：

> **短中周期动量选强 + 政金债提前承接 + 极弱市国债/政金债/现金替代混合 + 周频调仓**

具体可以拆成 5 层：

1. 风险池仍按 `25 日动量 + slope_085` 选强。
2. 常规防守池新增 `511580`，更早引入债券属性。
3. 弱市过滤时，把风险仓上限更早压到 `20%`。
4. 极弱市时，把剩余仓位切到：
   - `511260` 十年国债 ETF
   - `511580` 政金债 ETF
   - `CASH` 现金替代
5. 仅按周频调仓，降低噪音和换手。

---

## 4. 推荐参数

### 风险选择

- `lookback = 25`
- `signal_quality_method = slope`
- `signal_slope_penalty = 0.85`
- `leader_margin = 0.003`
- `absolute_momentum_threshold = 0.06`
- `weak_trend_defensive_weight = 0.70`

### top2 压仓

- `top2_close_gap = 0.007`
- `top2_risk_cap = 0.50`

### 弱市过滤

- `volume_ratio_20_60 < 0.93`
- `volume_ratio_5_20 < 0.92`
- `breadth_proxy < -0.02`
- `effective_momentum <= 0.18`
- `risk_cap = 0.20`

### 极弱市防守桶

- 触发条件：
  - `volume_ratio_20_60 < 0.91`
  - `breadth_proxy < -0.02`
  - `enter_days = 2`
  - `exit_days = 2`
- 防守桶权重：
  - `511260`: `50%`
  - `511580`: `30%`
  - `CASH`: `20%`

### 过热保护

- `pre_overheat_start_cut = 0.12`
- `pre_overheat_end_cut = 0.18`
- `pre_overheat_end_exposure = 0.80`
- `overheat_drawdown_cut = -0.015`
- `overheat_momentum_cut = 0.22`
- `overheat_max_exposure = 0.20`
- `overheat_high_momentum_cut = 0.27`
- `overheat_high_max_exposure = 0.08`

### 调仓频率

- `weekly`

## 5. 适用场景

更适合：

- 回撤容忍度低于基础版的账户
- 更重视稳定性而不是收益弹性的账户
- 希望把“弱市防守”显式落到债券 ETF 与现金替代上的账户

不太适合：

- 追求更高弹性、愿意接受更高换手的账户
- 希望在风格切换初期快速跟上的激进账户

---

## 6. 一句话结论

如果基础版是：

> **短中周期动量选强 + 防守池承接 + 弱市切债 + 过热降仓**

那么保守版就是：

> **短中周期动量选强 + 政金债提前承接 + 国债/政金债/现金替代混合防守 + 周频调仓**

它不是为了追求更高收益，而是为了把“防守优先”落实得更彻底。
