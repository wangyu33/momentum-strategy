# 未来 3 年美元利率走势与大类资产配置判断

更新日期：`2026-06-17`

关联历史底稿：[`fed_rate_cycles_1995_2026/README.md`](./fed_rate_cycles_1995_2026/README.md)

## 1. 先说结论

如果把未来 3 年压缩成一句话，我的基准判断是：

- **不是重新进入大级别加息周期。**
- **也不是回到 2020-2021 那种快速、深度降息环境。**
- **更像“高利率中枢下的慢降息 + 阶段性暂停 + 再通胀尾部风险”。**

也就是说，未来 3 年最可能出现的是：

1. `2026` 年以观望为主，降息次数很少，甚至全年不动。
2. `2027` 年如果增长继续放缓、通胀重新回落，才是主要降息窗口。
3. `2028-2029` 年联邦基金利率大概率回到 `2.75% - 3.25%` 一带，而不是重回零利率时代。

对应到配置上，最重要的不是简单押“降息利好风险资产”，而是接受一个现实：

- **现金和短债重新有战略价值。**
- **长久期债券只有在“通胀重新下去”时才值得大幅加仓。**
- **黄金仍然是未来 3 年最值得保留的宏观对冲资产。**
- **股票仓位要保留，但风格上应优先质量、现金流和定价权，而不是只押高估值久期资产。**

## 2. 当前所处位置：不是衰退前夜，更像“高位滞留”

截至 `2026-06-17`，市场处在一个很关键的位置：

- 政策利率已经从 `2025` 年末的连续降息中回到 `3.50% - 3.75%` 区间，但最近几次会议都是暂停。
- 增长并没有塌掉，`2026Q1` 美国实际 GDP 年化仍增长 `1.6%`。
- 就业没有失速，`2026-05` 非农新增 `17.2` 万，就业市场虽然降温，但失业率仍只有 `4.3%`。
- 通胀却重新抬头，`2026-05` CPI 同比升到 `4.2%`，核心 CPI 同比 `2.9%`；Fed 更看重的 `2026-04` PCE 同比 `3.8%`，核心 PCE 同比 `3.3%`。

这组组合意味着：

- Fed **没有被衰退逼着立刻大幅降息**。
- 但 Fed **也很难重新显著加息**，因为就业和金融条件并不支持再次剧烈收紧。
- 最现实的路径就是：**利率在偏高位置停留更久，等通胀重新确认回落后再缓慢下行。**

## 3. 历史经验给出的真正启示

仓库里的历史复盘已经有一个很重要的结论：

- 加息周期里，风险资产并不必然弱。
- 降息周期里，股票也不必然强。

从 [`fed_rate_cycles_1995_2026/README.md`](./fed_rate_cycles_1995_2026/README.md) 可以直接读出几个高价值模式：

1. **降息并不自动等于牛市。** 历史上如果降息对应的是衰退或信用收缩，股票和原油通常先跌，长债和黄金才是更直接受益者。
2. **长债只有在“增长放缓 + 通胀回落”同时发生时才真正舒服。** 如果只是降息预期升温、但通胀重新上行，长债并不会好做。
3. **黄金在加息尾声、降息初期、滞胀担忧阶段都可能有配置价值。** 这比很多人想象得更稳定。

这恰好和当前环境对得上：我们面临的核心问题不是“Fed 接下来是加还是减”，而是**未来 12-18 个月到底更像软着陆，还是更像高通胀黏性下的慢增长**。

## 4. 未来 3 年利率路径：三种情景

下面给出我认为最有用的三情景框架。

### 4.1 基准情景：高利率停留更久，之后缓慢降息

概率判断：`55%`

核心假设：

- 通胀在 `2026H2` 到 `2027` 年重新往下走，但速度不快。
- 劳动力市场继续降温，但不进入深衰退。
- 油价和地缘扰动带来波动，但不演化成持续失控的二次通胀。

利率路径判断：

- `2026` 年剩余时间：大概率 `0-1` 次降息，年底目标区间更可能在 `3.25% - 3.50%`，也不排除维持 `3.50% - 3.75%` 到年底。
- `2027` 年：成为主要降息窗口，全年累计降息 `50-75bp`。
- `2028-2029` 年：逐步接近新中性利率附近，终点大致在 `2.75% - 3.25%`。

这条路径意味着：

- 美元不会趋势性崩掉，但也难重回极强单边升值。
- 利率波动会比利率方向更重要。
- 股票仍可做，但估值扩张空间有限，收益更依赖盈利兑现。

### 4.2 乐观情景：通胀回落更快，软着陆兑现

概率判断：`25%`

核心假设：

- 能源冲击缓和，住房与服务通胀同步降温。
- 就业仅温和走弱，消费没有显著衰退。
- Fed 获得更大空间在 `2026Q4` 至 `2027` 年连续降息。

利率路径判断：

- `2026` 年：`1-2` 次降息。
- `2027` 年：累计再降 `75-100bp`。
- `2028` 年：利率回到 `2.50% - 2.75%` 一带并趋于稳定。

资产含义：

- 成长股、长久期债、REITs、港股/新兴市场弹性更大。
- 美元偏弱，黄金未必最强，但仍有组合对冲价值。

### 4.3 悲观情景：再通胀或类滞胀，Fed 长时间不降甚至重启加息

概率判断：`20%`

核心假设：

- 能源、地缘、财政或供给侧因素导致通胀重新上冲。
- 增长不强，但通胀下不去，形成“慢增长 + 高通胀”的类滞胀组合。
- Fed 被迫把“更久高利率”维持到 `2027` 年，极端情况下再加 `25-50bp`。

利率路径判断：

- `2026` 年：不降，甚至重新上调。
- `2027` 年：政策利率仍停留在 `3.75% - 4.25%` 附近。
- `2028-2029` 年：只要通胀黏性不解除，就难以回到 `3%` 下方。

资产含义：

- 长债最难受。
- 高估值成长股估值压力最大。
- 黄金、能源、现金、短久期债会明显占优。

## 5. 对资产配置的直接映射

### 5.1 未来 3 年最值得坚持的配置原则

1. **把“现金 / 短债”当作正式资产，而不是临时过渡仓位。**
2. **不要在“通胀还没彻底下去”时重仓长久期债。**
3. **黄金应该保留战略仓位。** 未来 3 年无论走向软着陆、衰退还是类滞胀，黄金都不是多余配置。
4. **股票不宜空仓，但要降低对单一叙事的依赖。** 最稳的思路是质量股 + 全球分散，而不是只押单一市场的高弹性板块。
5. **商品和能源仓位不需要大，但要有。** 这是对抗再通胀尾部风险最便宜的保险之一。

### 5.2 一个适合中性风险偏好的基准组合

如果投资期限是 `3` 年左右，且目标是“争取跑赢通胀，同时不想把组合完全押在单一宏观叙事上”，我更倾向下面这组基准权重：

| 资产 | 权重 | 作用 |
| --- | --- | --- |
| 现金 / 美元货基 / 0-2 年短债 | 20% | 吃票息，保留流动性，应对高利率停留更久 |
| 3-7 年美债 / 高等级债 | 20% | 作为温和降息的主要受益仓位 |
| 10 年以上长久期美债 | 8% | 只保留战略仓位，防衰退，但不过度押注 |
| 美股质量龙头 / 宽基 | 22% | 获取盈利增长和全球核心权益暴露 |
| 非美发达市场股票 | 8% | 分散美元单一风险 |
| 新兴市场 / 港股 | 7% | 押软着陆与美元回落时的弹性 |
| 黄金 | 10% | 对冲通胀、地缘、实际利率回落 |
| 商品 / 能源 | 3% | 对冲再通胀尾部 |
| REITs / 实物资产权益 | 2% | 提供通胀敏感资产补充 |

合计：`100%`

这套组合的核心思想不是追求单一年度收益最大化，而是覆盖三种路径：

- 软着陆时，股票和中久期债有收益。
- 衰退时，长债和黄金托底。
- 再通胀时，现金、短债、黄金、商品能缓冲。

### 5.3 如果你更保守

可以把组合改成：

- 现金 / 短债 `30%`
- 3-7 年债 `25%`
- 长债 `5%`
- 股票总计 `25%`
- 黄金 `12%`
- 商品 `3%`

这种配法的优点是：即使未来 12 个月 Fed 一直不降，组合也不会因为错误押注长债而太难受。

### 5.4 如果你更激进

可以把组合改成：

- 现金 / 短债 `10%`
- 3-7 年债 `15%`
- 长债 `10%`
- 股票总计 `50%`
- 黄金 `10%`
- 商品 `5%`

但前提是你能接受：

- 如果 `2026H2` 再通胀继续发酵，净值可能先承压。
- 这种激进组合更依赖“通胀回落 + Fed 重新降息”的乐观情景兑现。

## 6. 哪些资产该高配，哪些不该重仓

### 建议高配或保留核心仓位的

- **现金 / 货基 / 短债**：未来 6-12 个月仍然有很强性价比。
- **3-7 年中期美债**：比长债更稳，是基准情景下赔率更好的利率资产。
- **黄金**：未来 3 年几乎每种宏观路径下都有存在理由。
- **美股中的高质量宽基与龙头**：在慢增长世界里，盈利和现金流稳定性更重要。
- **适量非美与新兴市场敞口**：不是因为一定最强，而是因为一旦美元走弱，它们弹性更大。

### 不建议一开始就重仓的

- **超长久期债券**：只有在核心通胀明确下行时才值得大幅加码。
- **纯高估值成长风格**：它对实际利率很敏感，在高利率停留更久时容易被估值杀伤。
- **高杠杆 REITs**：如果融资成本长时间高位，其盈利修复会慢于市场想象。

## 7. 未来 12 个月最关键的三个观察点

后面如果要动态调整仓位，我会重点盯这三件事：

1. **核心 PCE 能否回到 `3%` 下方并持续走低。**
2. **失业率是否从 `4.3%` 明显上行到 `4.7% - 5.0%` 区间。**
3. **油价与地缘事件会不会把通胀重新推高。**

对应动作可以非常简单：

- 如果 **通胀下行 + 失业上升**：提高长债和成长股权重。
- 如果 **通胀黏性 + 就业仍稳**：继续偏配现金、短债、黄金，中期债优于长债。
- 如果 **通胀再起 + 增长走弱**：进一步减长债、减高估值权益，增黄金和商品。

## 8. 最终判断

未来 3 年，我不认为美元利率的主线是“重新大幅加息”，也不认为会“快速深度降息”。

更可能的现实是：

- **2026：高位停留，少降或不降。**
- **2027：缓慢降息。**
- **2028-2029：回到约 3% 的新中枢附近。**

因此，大类资产最合理的打法不是单押一种情景，而是围绕下面这条主线搭组合：

- 用 **现金 / 短债** 吃高利率时代的确定性；
- 用 **中期债** 等待真正的降息兑现；
- 用 **黄金** 对冲政策与地缘不确定性；
- 用 **质量股 + 全球分散股票** 保留长期增长敞口；
- 用 **少量商品** 防守再通胀尾部。

如果只留一句最实用的话，那就是：

> 未来 3 年最怕的不是“没押中第一次降息”，而是过早把组合全部切到长债和高估值成长，结果遇到高利率停留更久。
