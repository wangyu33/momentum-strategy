# Libra 实验分析：72022691

## 实验信息

- 实验链接：`https://libra-sg.tiktok-row.net/libra/flight/72022691/report/main`
- 实验名称：`[SEO] video页 add sim text recall`
- App：`tiktok_webapp`
- Owner：`wangyu.remm`、`qinmeilin.hqh`
- 实验区域：`TX`、`SG`、`VA`、`EU_TTP`
- 观察口径：TikTok ROW，`bytedcli --site i18n-tt`
- 数据说明：报表当前使用的是累计口径；可用累计区间从 `2026-05-19` 开始，到 `2026-05-23` 的 fallback 数据，`2026-05-24` 还有部分地区包未完全导入

## 版本设计

- `v1`：对照组
- `v2`：使用 `tier3` 作为细分召回
- `v3`：不使用 `tier3` 作为细分召回，同时开启 `first_video_emb`
- `v4`：在 `v3` 基础上增加相关性 `boost`

## 结论摘要

**不建议基于这次实验结果直接上线任何实验组。**

原因有两点：

1. 业务核心关注的 `DNU` / `DNU CVR` 没有拿到统计显著的正向结论。
2. `CTR (UV)` 在三个实验组都出现了统计显著下降，属于明确负向信号。

如果一定要在三组里做相对比较，`v3` 相比 `v2` 和 `v4` 更接近“最不差”的方案，但仍然不满足上线标准，因为它同样带来了显著的 `CTR (UV)` 回退。

## 版本对比判断

### v2

- 优点：`DNU` 和相关 CVR 有轻微正向
- 风险：`CTR (UV)` 显著下滑
- 结论：不建议上线

### v3

- 优点：`DNU` 提升幅度在三组里相对最高，`CTR (UV)` 回退略小于 `v2` / `v4`
- 风险：`CTR (UV)` 依然显著下滑，DNU 相关指标仍不显著
- 结论：相对最优，但仍不建议上线

### v4

- 优点：没有看到比 `v2` / `v3` 更强的收益
- 风险：`CTR (UV)` 跌幅最大，DNU 端也没有补回来
- 结论：三组里最不推荐

### 拆维度后的结论

`tap_target_group` 拆开之后，结论更清楚了：

1. `ALL Targets` 的负向仍然成立，说明实验整体体验确实受损。
2. `Launch Popup` 基本稳定，甚至在 `v3` 上出现局部 CVR 正向。
3. `Login Popup` 有弱负向趋势，但不显著。
4. 因此，这次实验的主要问题大概率**不在 Launch/Login Popup 这两个默认重点入口**。

更合理的推断是：

- 负向影响主要来自其他 tap target 或更广义的页面点击意愿下降。
- 下一步应该优先拆查这些入口：
  - `Bottom Banner`
  - `Comment Section`
  - `Hot Video`
  - `Hot Video Preview`
  - `Search Recommendations`
  - `Video Play Area`

所以，加入 `tap_target_group` 分析后，结论不是变得更乐观，而是变得更明确：

- 这次实验的坏结果并不是 `Launch Popup` / `Login Popup` 这两个已关注入口拖出来的。
- 问题更可能出现在其他点击承接位，或者召回结果本身降低了用户点击意愿。

## 最终分析结论

这次实验不能支持“sim text recall 改动能稳定提升 SEO video 页核心业务结果”的结论。

更准确地说：

- 召回改动在 `DNU` 上只有方向性小幅提升，没有统计显著性支撑。
- 同时带来了显著的 `CTR (UV)` 下降。
- 因此从收益风险比看，这次实验整体是**负收益或至少不具备上线充分性**。

## 建议动作

1. 不直接发布 `v2` / `v3` / `v4` 任一版本。
2. 如果要继续迭代，优先以 `v3` 为基础做下一轮小步实验，因为它相对损伤最小。
3. 下一轮重点排查为什么召回扩展后：
   - 页面点击意愿下降
   - `CTR (UV)` 明显回退
   - 但后链路 `CVR` 没有同步改善
4. 建议下一轮补看这几个拆维度：
   - `tap_target_group`
   - `page_name`
   - `region_code`
   - 新老用户 / 登录态
5. 如果业务目标优先级真的是 `DNU`，那下一轮要明确判定标准：
   - `DNU CVR` 至少显著为正
   - 且 `CTR (UV)` 不出现显著负向
