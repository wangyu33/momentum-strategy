# 非动量策略二次筛选记录

## 1. 这次重点筛什么

上一版极简风险平价很一般，所以这次不再凭感觉换名词，而是直接在同一组 ETF 上筛几类典型非动量策略：

1. 等权多资产
2. 逆波动风险平价
3. 低波前三等权
4. 最小方差启发式
5. 最大分散启发式
6. 全天候 / 静态风险预算

## 2. 在同一 15 年样本里的离线比较

同一资产池：`SPY / EFA / EEM / IEF / VNQ / GLD / DBC`

粗筛结果：

- 等权多资产：年化约 `10.10%`，Sharpe 约 `0.53`，最大回撤约 `-30.38%`
- 逆波动风险平价：年化约 `6.90%`，Sharpe 约 `0.47`，最大回撤约 `-29.38%`
- 低波前三：年化约 `6.56%`，Sharpe 约 `0.53`，最大回撤约 `-32.09%`
- 最小方差启发式：年化约 `6.82%`，Sharpe 约 `0.38`，最大回撤约 `-30.38%`
- 最大分散启发式：年化约 `7.43%`，Sharpe 约 `0.41`，最大回撤约 `-30.38%`
- 全天候静态配置：年化约 `8.30%`，Sharpe 约 `0.66`，最大回撤约 `-19.49%`

## 3. 为什么最后落全天候

它不一定有最高收益，但有三个优点：

1. 风险收益比明显更平衡。
2. 回撤显著低于等权多资产。
3. 规则几乎没有可调参数，比较不容易过拟合。

## 4. 本地采用的最小实现

这次故意不做复杂宏观模型，只做最简单的战略配置：

- `IEF` `35%`
- `SPY` `20%`
- `GLD` `15%`
- `EFA` `10%`
- `DBC` `10%`
- `EEM` `5%`
- `VNQ` `5%`

月末只做一件事：

- 如果权重漂移了，下月首个交易日拉回目标配比。

## 5. 这类策略的真实定位

这不是暴利策略，也不是高胜率择时系统。

它更像一套长期资产配置框架：

- 牛市里通常跑不过纯股或者强动量。
- 但大波动和滞胀阶段，组合韧性通常更强。
- 如果用户要的是“非动量、可长期拿、回撤别太难看”，它比上一版风险平价更合适。
