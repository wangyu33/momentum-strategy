# 经典价值投资策略复现（A 股）

基于 akshare 免费数据，在中证 800 成分股上复现并检验 **42 个**价值/质量/异象选股策略，
用统一、无未来函数的回测框架做横向对比。

**核心结论先说**：在 2008–2026 的中证 800 池里（随机选股中位 ≈ 11.3%）：

1. A股大中盘的"低估值"本身不是 alpha：经典价值 20 个策略几乎全部跑不赢随机，
   PB-ROE 残差甚至是**严格单调的反向因子**（见「第二轮分层检验」）；
2. 第三轮起转向异象类：**PEAD/SUE 是第一个多维稳健的 alpha**（季度 19.60%、
   胜过 100% 随机、回撤全场最浅）；
3. **第四轮挖出第二个真 alpha：营收超预期 SUR**（季度 23.87%，与 SUE 相关性仅 0.375，
   剔除小市值后仍 16.3%）；同轮证伪了表观很强的 Amihud 非流动性与低换手——
   两者都是「小市值的马甲」（剔池内最小 30% 市值后崩到 10% 附近）；
4. 小市值 41.47%（年度）不可信，是幸存者偏差的教科书案例（见第三轮结论 3）。

## 回测纪律（防自欺的部分）

| 环节 | 做法 |
|---|---|
| 选股可见性 | 财报按**法定披露截止日**生效（一季报 5/1、半年报 9/1、三季报 11/1、年报次年 5/1），调仓日只能看到已生效财报 |
| TTM | 新浪财务是**年初至今累计值**（已验证：ROE 一季报中位 2.02% vs 年报 8.51%），TTM = 本期 + 上年Q4 − 上年同期 |
| 成交价 | 调仓日 T 收盘决策，**T+1 收盘成交**；收益用后复权价（分红再投资） |
| 估值 | PE/PB/股息率用**不复权价**计算（混用后复权价会让估值失真） |
| 成本 | 买入 0.15% / 卖出 0.20%（含佣金、印花税、冲击成本） |
| 分红 | 新浪「派息」为每 10 股口径（已用茅台/工行/招行三个样本核对），除权除息日后计入过去 12 个月股息 |

| **市赚率 PR** | PR = PE / ROE（ROE 取百分数） | 无偏差（丁宁 ericwarn 原定义） |

| **红利低波（H30269）** | 3年连续分红→剔支付率前5%→股息率前75→波动率升序前50 | 两处近似：连续3年分红用「近1年有+近3年累计>0」；股利增长非正用「近1年≥3年均值×0.8」 |

## 三个关键发现

### 1. 低估值本身在中证800 里不是 alpha

PB 五分位：P1(最低) 9.8% → P2 8.2% → P3 11.1% → **P4 12.6%** → P5 11.5%。
**完全不是单调的价值效应**，最便宜的 20% 表现最差之一。
原因：A股大中盘的"便宜"长期集中在银行、地产、钢铁——低估值是行业属性，不是错杀。

### 2. F-Score 在低估值组内确实有效，但幅度远小于原论文

低 PB 前 20% 内按 F-Score 分层：F0-3 **10.1%** → F4-6 10.9% → F7-9 **11.7%**，单调，
F7-9 比 F0-3 高 **+1.57pp/年**，方向与 Piotroski(2000) 一致。
但原论文在美股 1976-1996 的高 BM 组内做到 7.5pp/年的多空差，A股大中盘只有 ~1.6pp
——信息含量被大中盘的高覆盖度稀释了。

### 3. 金融股是价值策略的隐形拖累

剔除银行/证券/保险后（2013 起）：PE+PB +3.47pp、高股息 +2.78pp，
而 Piotroski 和纯低 PB 几乎不变。传统价值策略的候选被金融股占据，
而金融股 2013 年后长期低回报。

### 4. PB-ROE 残差法不但没修复非单调，反而成了严格单调的**反向**因子

这是第二轮最硬的负面结果。残差法的设计初衷正是修复「低 PB 里混着低 ROE 银行」的问题
（在同等 ROE 水平下比估值），实测却走向反面：

| 因子 | P1(理论最优) | P2 | P3 | P4 | P5 | P1−P5 | 单调 |
|---|---|---|---|---|---|---|---|
| PB（对照） | 9.75% | 8.25% | 11.11% | 12.58% | 11.52% | −1.77pp | 否 |
| **PB-ROE 残差** | **8.81%** | 9.16% | 11.59% | 14.56% | 15.36% | **−6.55pp** | **是（递增）** |

近段（2017 起）同样是严格递增：9.32 / 9.77 / 13.75 / 16.54 / 17.42，P1−P5 = −8.11pp。
也就是说，**残差越负（越"便宜"）的一组长期表现越差，而且比纯 PB 更极端、更单调**。
一个合理解释：中证800 里残差为负的多是银行/地产/钢铁，市场对其高 ROE 的可持续性
本就打了折，事后看市场是对的——便宜有便宜的道理。

### 5. Novy-Marx GP/A 在 A 股中证800 不成立

| 区间 | P1(最高GP/A) | P2 | P3 | P4 | P5 |
|---|---|---|---|---|---|
| 2008 起 | 9.54% | 12.55% | 12.29% | 11.32% | 7.03% |
| 2017 起 | **5.22%** | 13.55% | 16.78% | 15.19% | 6.87% |

不是单调递增，而是**两头差、中间好**。近段最高 GP/A 档只有 5.22%，是所有组合里最差的之一，
与论文（高 GP/A 显著跑赢）完全相反。GP/A 在 A 股大中盘既不能正向选股、也不能反向剔除。

### 6. 市赚率（丁宁）作为选股因子无区分度

PR 五分位：8.44 / 9.25 / **15.77** / 10.56 / 10.31，非单调；加了支付率修正系数 N 之后
（8.08 / 11.14 / 9.96 / 9.48 / 12.48）依然非单调。
「双5」硬门槛版候选常年不足 5 只（平均 4.5），年化仅 4.39%，实盘不可用。
需要说明的是：丁宁本人的用法是**少数个股 + 定性研判 + 长期持有**（且明确排除周期股、
科技股、成长股），本框架做的是全池机械排序，两者不是同一件事。

### 分层检验（季度，五分位年化，P1 = 理论最优档）

| 因子 | P1 | P2 | P3 | P4 | P5 | P1−P5 |
|---|---|---|---|---|---|---|
| **SUE（2008起）** | **19.60** | 19.04 | 16.25 | 11.79 | 13.33 | **+6.27** |
| SUE（2017起） | 16.31 | 15.53 | 9.79 | 7.34 | 13.50 | +2.81 |
| 12-1 动量（2008起） | 15.09 | 12.72 | 10.42 | 12.30 | 8.77 | +6.33 |
| 12-1 动量（2017起） | **25.21** | 15.03 | 12.95 | 13.92 | 8.80 | **+16.41** |
| 1月反转（2008起） | 11.72 | 7.85 | 11.65 | 10.23 | 8.16 | +3.55 |
| 低波动1年（2008起） | 8.93 | 8.13 | 11.06 | 12.66 | 9.15 | −0.21 |
| 低特质波动（2008起） | 7.83 | 8.72 | 10.60 | 12.83 | 10.48 | −2.65 |

| 6月反转（2008起） | 6.12 | 9.65 | 9.77 | 11.28 | 15.06 | −8.94 |

**没有任何一个是严格单调的**，但 SUE 与动量的 P1 档显著领先，且 SUE 的 P1、P2 双档
（19.60 / 19.04）远高于其余各档——这是三层检验里唯一呈现「头部集中」形态的因子。

### 结论 1：SUE 是三轮里唯一多维稳健的 alpha

| 维度 | 结果 |
|---|---|
| 持仓数 | 10 只 21.57% / 20 只 21.14% / 30 只 19.60% / 50 只 19.68% / 80 只 20.47% |
| 交易成本 | 零成本 20.31% → 正常 19.60% → 高成本(0.3/0.4%) 18.89%（成本吞噬 <1.5pp） |
| 起点 | 2008 起 19.60% / 2013 起 16.50% / 2017 起 16.31% |
| 分段 | 2008-2016 **23.61%** / 2017-2021 **25.21%** / 2022-2026 7.45% |
| 风险 | 最大回撤 -48.9%，是全部 32 个策略里**最浅**的（池内等权 -59.1%） |

换手只有 1.68/年，成本影响极小；三段行情全部为正；回撤最浅。
这是本项目目前唯一在「收益 + 回撤 + 稳健性」三项上同时站住的因子。
唯一弱点：2022-2026 年化降到 7.45%，弱于池内等权。

### 结论 2：低波动族不是 alpha，是降风险

低波动 / 低 IVOL / 低 Beta 三个策略年化 7.8~8.9%，**都跑输随机**，
与 Blitz(2021)「A股最低1/10 跑赢最高1/10 年化12.9%」的结论相反。
但它们的**回撤显著更浅**：-46.4% / -53.6% / -55.7% vs 随机 -59.4%。
分段看低波动在 2017-2021 只有 3.19%（最差），2022 后回到 10.17% ——
A 股低波异象高度依赖行情阶段，不是一个可以无脑长期持有的因子。

### 结论 3：小市值 36.77% 不可信，是幸存者偏差的教科书案例

持仓 10/30/60 只分别 40.12% / 36.77% / 34.04%，2008-2016 年化 23.28%、2017 后 50.57%。
**但这是本项目偏差最严重的一个数字**，理由有三：

1. 池子是**当前**中证800 成分回溯 18 年。今天仍在指数里、且市值排名最末的 30 只，
   在 2008 年根本不是「中证800 的小盘股」——它们是后来才被调进来的成长股。
   这是纯粹的后视选择，实盘无法复制。
2. 市值用「当前股本 × 历史价格」估算，忽略了 18 年间的送转、增发、回购。
3. 真正的 A 股规模因子收益主要来自中证800 **之外**的微盘股，本池测不到。

同理，**12-1 动量在 2008-2016 只有 5.40%**，2017 后才到 29.69% / 22.45%——
它的收益高度依赖 2017 后的核心资产行情，不能当作稳定因子。

### 一次必须记录的实现 bug（影响前两轮结论）

本轮写完新策略后做了**方向自检**（选中组的主要因子值 vs 全池中位数），
发现 `rank_pct(col, ascending=False)` 配合 `select()` 取分数最大者，
会选出**方向完全相反**的一组股票。三个策略中招：

| 策略 | 实际选中 | 应为 | 修正前 → 修正后（年度） |
|---|---|---|---|
| Novy-Marx GP/A | 最低 GP/A 0.04 | 最高 | 5.34% → **9.53%** |
| GP/A + 价值 50/50 | 最低 GP/A / 最低 EP | 最高 | 7.06% → **9.85%** |
| 红利低波 H30269 | 低股息 + **高**波动 | 高股息 + 低波动 | 11.83% → **8.93%** |

**上一轮报告里「红利低波 11.83% 站住」是错的**——那实际上是「低股息高波动」组合的成绩。
修正后红利低波回落到 8.93%（胜过随机 5%），不再站得住。
分层检验脚本用的是独立实现的 `_goodness()`，方向一直正确，**分层结论不受影响**。

现已加入 `DIR_CHECK` 自检表（`/tmp/snapws/robust3.py` 第 1 节），覆盖 24 个策略。

### 结论 1：SUR（营收超预期）是第二个真 alpha

SUE 的营收版：`SUR = (单季营收 Q_t − Q_{t−4}) / 过去同比增量标准差`。
新浪财务不直接给单季营收，用 **营收 ≈ 年化总资产周转率 × 总资产** 还原。

数据可靠性已交叉验证：
- 估算营收 vs 「净利/净利率」独立反推路径：对数相关 **0.927**、截面秩相关 **0.922**、比值中位 0.99
- corr(SUR, SUE) = **0.375**——与盈利超预期只是弱相关，是相对独立的信息源
- corr(SUR, 市值) = **0.062**——与小市值无关（这正是它与 Amihud 的本质区别）

稳健性矩阵（`experiments/robustness_round4.py`）：

| 维度 | SUR | SUE+低换手 |
|---|---|---|
| 剔除池内最小 30% 市值 | **21.71%** | 14.03% |
| 剔除池内最小 50% 市值 | **16.31%** | 12.13% |
| 分段 2008-16 / 2017-21 / 2022-26 | **33.78 / 28.65 / 20.29** | 全部为正 |
| 月度调仓 | **28.77%** | - |
| 持仓 10 只 / 80 只 | 25.41% / 24.23% | - |
| 3 倍交易成本 | **26.96%** | - |

全部通过。SUE 通过了同样检验但幅度更小；而 Amihud/低换手在「剔小市值」下
直接崩塌到 10.4% / 9.5%（低于随机 11.26%）——**不做市值中性化就会被骗**。

### 结论 2：Amihud 与低换手是「小市值的马甲」

- Amihud 非流动性与市值的秩相关高达 **-0.77**，低换手为 -0.30
- 两者表观年化 24.9% / 22.7%，剔除池内最小 30% 市值后剩 10.4% / 9.5%
- 这两个策略**保留在库中并标注[已证伪]**，作为「表观收益 ≠ alpha」的反面教材

### 结论 3：为什么 A 股做价投难——价值陷阱诊断

对低估值组的持仓结构做了诊断（`experiments/diagnose_value_trap.py`）：

- 低 PE 组 **38.7% 是银行**（组内资产负债率中位 80%），低 PB 组银行占 27.3%；SUE 组银行仅 8.7%
- 关键检验：**剔除银行/金融/地产/强周期后，价值因子并不改善**（低 PB 10.81% → 9.77%）
- 结论：**不是行业错配的问题，是 A 股大中盘的低估值溢价本身不存在**——
  低估值系统性地对应「市场认为基本面会恶化」的定价，而这个定价在过去 18 年大体是对的
- SUE 剔除银行后反而更好（19.60% → 22.00%，回撤 -48.9% → -45.3%）：
  超预期 alpha 与金融股无关，实盘可考虑直接剔除金融

## 稳健性

- **起点敏感**：2008 起全策略 8–12%，2013 起升到 12.9–15.6%——2008 顶部起算 + 2011-12 熊市重仓价值股是主要拖累
- **持仓数**：10/20/30/50 只差异不大（±2pp 内），结论不依赖持股数
- **调仓频率**：年度普遍优于半年（-0.1~-1.6pp），低频是价值策略的正确打开方式
- **Piotroski 在 4 个起点上全部为正**：11.91% / 15.17% / 12.45% / 15.66%

## 已知局限（诚实清单）

1. **幸存者偏差（最重要）**：股票池是**当前**中证800 成分回溯 2008 年。
   能留在指数里的都是赢家，所有组合（含随机对照）的绝对收益都被高估。
   但策略 vs 随机 vs 池内等权用的是**同一个池子**，相对对比仍然成立——
   这正是本报告把「随机30只」作为主对照的原因。
2. **基准不含股息**：沪深300 用的是价格指数，策略净值含分红再投资，
   「超额年化」里约 1.5–2pp 是股息差，不是选股能力。
3. **生效日用法定截止日而非实际公告日**：实际公告可能更早，选股略偏保守，方向上不吃未来函数。
4. **财务字段缺失**：毛利率 2008-2014 缺失约 38%（用营业利润率兜底），长期负债率缺失 21%，
   F-Score 单项缺失按 0 分计并以 `f_score_n` 记录有效判据数。
5. **格雷厄姆防御型/施洛斯/净净股候选极少**（5.7/10.7/1.7 只），
   实盘不可执行，其回测数字波动极大，仅作展示。
6. **净净股是近似实现**，不代表原版 NCAV 结论。
7. 单一数据源（新浪），未经交叉验证。
8. **新浪「总资产周转率」是报告期累计值**（实测中位 0.137，是单季口径），
   GP/A 已按 `4/季度` 年化；若后续改用季度调仓，需注意不同报告期的年化系数不同。
9. **财报「股息发放率(%)」字段口径不可信**（实测中位 0.025，既不像百分数也不像小数），
   修正市赚率的派息率改用自算的 `近12月每股派息 / TTM每股收益`。
10. **红利低波是近似复现**：编制方案要求「过去3年连续分红」与「每股股利增长率」，
    本框架只有分红流水，前者用「近1年有分红 且 近3年累计>0」代替、
    后者用「近1年股息率 ≥ 3年均值×0.8」代替；且原版为股息率加权，此处为等权 30 只。
11. **未做行业中性化**：券商口径的 PB-ROE 通常行业内标准化后再回归，
    本框架缺行业分类数据，全部为全池截面回归，行业暴露未受约束。
12. **小市值策略的偏差是全项目最大的**（见第三轮结论 3）：当前成分回溯 +
    用当前股本估历史市值 + 池内不含真正的微盘股，41.47% 不可作为任何预期依据。
13. **SUE 依赖财报序列连续性**：`diff(4)` 要求各期报告齐全，
    个别公司缺报告期会让同比基期错位（结果为 NaN 而非错值，但会损失样本）。
14. **季度调仓下的随机对照中位是 11.26%**，与年度的 11.63% 不同——
    跨频率比较策略收益时必须用同频率的对照组。
15. **SUR 的营收是估算值**：`营收 ≈ 年化总资产周转率 × 总资产`（新浪无单季营收字段）。
    已用「净利/净利率」独立路径交叉验证（截面秩相关 0.922），但绝对值有误差；
    覆盖率约 64%（需 8 期以上财务历史），早期样本偏少。
16. **EBIT/EV 与 OCF/NI 是近似字段**：EBIT/EV 缺现金科目（EV 系统性偏高），
    只能用于同截面排序；OCF/NI 依赖财报原字段口径，实测无区分度。
