### 候选清单与可实现性
**A. 学术经典（海外）**
1. Novy-Marx GP/A（2013《The Other Side of Value》）— 毛利润/总资产。
   关键：可用 gross_margin × asset_turnover 直接算出，无需新数据。
   论文结论：预测力与 B/P 相当，两者相关 -0.57，50/50 组合 Sharpe 0.85 vs 单腿 0.14/0.27。
   → 可做，且是最有理论支撑的补强方向
2. Sloan 应计异象（1996）— (净利-经营现金流)/总资产。
   可用 (eps_ttm - ocfps_ttm) × shares / total_assets → 可做
3. Cooper 资产增长（2008）— 总资产同比增速越低越好 → asset_growth 字段已有 → 可做
4. Acquirer's Multiple EBIT/EV（Greenblatt/Gray 认为优于 PE）—
   EBIT 无直接字段，需 op_margin2 × asset_turnover × total_assets 估算；
   EV 需总负债(可由 debt_ratio×total_assets 估)但缺现金 → 近似可做，误差需说明
5. Wesley Gray《Quantitative Value》核心发现：
   魔法公式超额**全部来自价值腿（EBIT/EV），质量腿无贡献**——
   单独 EBIT/EV 15.95% vs 魔法公式 13.94% vs 单独 ROC 10.37%（1974-2011）
   → 这解释了我们复现的 magic_formula 只有 7.42% 的一部分原因
6. QMJ（Asness 2013）：盈利/成长/安全/分红四支柱 → 缺股本时间序列，payout 腿做不了，
   beta/波动/ROE波动 可由价格与历史 ROE 算出 → 只能做 3/4，需标注不完整
7. Beneish M-Score：需应收/折旧/营收明细 → 字段不足，**做不了**

**B. A 股实证（券商研报口径）**
1. **PB-ROE 残差法 ★首选**：ln(PB) 对 ROE 截面回归取残差，残差小=低估。
   - Wilcox(1984) 原始模型；长江金工《基础因子研究(十二)》验证中证800内分位数法有效
   - 中信证券(2026-08-30)：高轮动环境下残差法月均跑赢中证全指 158bps，
     加"困境反转"因子后 179bps；低PE/低PB 月均 219/196bps
   - 国联民生(2026-08-28)：PB-ROE 均衡风格 2015-2026.8 年化 17.89%，超偏股基金指数 8.98pp
   - 中证招银理财质价甄选指数(932732) 即为该法的产品化：等权50只、季度调仓
   → **PB、ROE 都有，零新数据即可实现，优先级最高**
2. EP 剔除微利股：国投证券——每期剔归母净利<1000万（约 16%）后 EP 因子
   RankIC 6.61→6.86%，多空年化 18.82→23.19% → 可做（是个廉价改进）
3. CFP（经营现金流/市值）：剔 FCFE<0（占 59%）后 RankIC 0.81→1.75% → 可做
4. 价值+短期反转：A股散户占比高，1月内反转显著强于动量 → 价格可算，可做
5. 估值中枢稳定性（过去3年 EP 均值/标准差）→ 需历史 EP 序列，可做但需滚动窗口

**C. 公开指数方案（编制方案完全公开，可逐条复现）**
1. 中证红利低波 H30269：过去3年连续分红且股息率>0；剔支付率前5%、股利增长非正；
   按3年平均税后股息率取前75，再按1年波动率升序取前50；股息率加权，单样本≤15%
   → 分红+价格都有，**可完整复现**
2. 中证全指自由现金流 932365 / 国证自由现金流 980092：
   核心 FCF/企业价值，剔金融地产，100只，季度调样。
   → **缺资本开支字段，严格版做不了**；可用"经营现金流/市值(CFP)"做降级近似
3. 富时中国A股自由现金流聚焦：50只，加波动率+预期成长剔除 → 缺预期数据，做不了

### A股因子共识（多来源交叉一致）
- 价值：PB 最稳健，PE 次之；深度价值（低估值+盈利稳定）长期有效
- 质量：ROE/ROA/毛利率，A股最稳定的因子之一
- 规模：小盘溢价显著（2016 后减弱）
- 动量：**A股不吃动量，1个月内偏反转**，6-12个月不稳定
- 低波：有效，高波反而差
- 红利：高股息长期有效，中证红利低波是典型

### 与我们已有结论的呼应
我们测出 PB 五分位非单调（P1 9.8% ... P4 12.6%）——这恰恰是"单腿低PB无效"的证据，
PB-ROE 残差法正是为此设计的（在同等 ROE 水平下比估值），理论上应能修复非单调性。

### 建议落地顺序（待用户确认）
1. PB-ROE 残差法（零新数据，A股实证最强，直接针对我们的非单调问题）
2. Novy-Marx GP/A（零新数据，理论支撑最硬）
3. 应计 + 资产增长（零新数据，可与 F-Score 组合成"质量增强价值"）
4. 红利低波 H30269 复现（方案公开，可做绝对收益参照）

## 【追加】回撤开仓点分析（momentum_backtest，用户问"开仓点在回撤多少比较好"）

新增 `analyze_entry_points.py`（读 output/core/backtest_nav.csv 日频净值，2012-05~2026-09-22，当前回撤 -1.39%，历史最深 -16.57%）。三种口径：

1. 逐日分桶（回撤深度 → 未来收益，实时可观测）：
   - 回撤越深短期胜率越高：21日胜率 0~1%桶 47% → 3~5%桶 68% → 10~13%桶 73% → >13%桶 84%
   - 252日均收益：-3~-5%桶最高 35.42%、-7~-10%桶 35.08%；深桶(>10%)反而 28~31%
   - 买入后最大浮亏随深度递减：21日中位 0~1%桶 -1.81% vs >13%桶 -0.26%
2. 事件口径（每次回撤只取最深点）：深桶 21日均 8~10%、胜率100% —— 但有前视偏差（事后才知道最深点），仅验证方向
3. 分批建仓模拟（等分资金等到指定回撤再投，未投入按 2% 计息，起点滚动 546 个）：
   - 3年窗口：立即全仓 24.62% ≈ -3%全仓 ≈ -5%全仓(-0.06pp)；-8%全仓 -1.39pp；分3批-3/-5/-7 -0.24pp；定投 -12.4pp
   - 1年窗口：-3%全仓 25.04%（+0.36pp 优于立即）；-8%全仓 -6.36pp 且 7% 概率等不到；定投 -13.7pp
   - **结论：等 -8% 以上明显不划算，定投最差**

建议（已告知用户）：最佳开仓区 **-3%~-5%**（收益最高+胜率跃升+回本快中位24天+样本590天充足）；实操分3批 -3/-5/-7 或 -2/-4/-6（年化代价<0.3pp，换胜率47%→68%+、浮亏-1.8%→-1.4%）；不要等 -10%（机会成本>择时收益）；当前 -1.39% 处于次优区。风险提示：单条净值路径、深桶样本少且重叠、策略有过拟合前科。
