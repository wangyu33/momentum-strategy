## 【重要更正】撤回「十年国债入 RISK 组」建议

### 更正原因：+0.50pp 全靠 3 个交易日，是噪声不是 alpha

**dual 层 signal 只变了 17 天**（3481 天中），全部是「空仓 → 防守资产」：
- 空仓→黄金 15 天、空仓→豆粕 1 天（2020-03-19）、空仓→红利低波 1 天
- 年份分布：2018 年 11 天、2024 年 3 天、2017/2020/2021 各 1 天

**机制**（读 core/signals.py build_threshold_dual_signal 确认）：
- RISK 组最强动量 r_score > 5% → 买 RISK 组最强，满仓
- 0 < r_score ≤ 5% → 买 DEF 组最强，仓位 = weak_trend_defensive_weight
- r_score ≤ 0 且 DEF 最强动量 d_score ≤ 0 → **空仓**（both_weak_for_cash）
- 加入国债后，当所有进攻资产动量均为负、但国债动量微正（均值 +0.38%）时，
  r_score 变正 → both_weak_for_cash 不成立 → 策略**不再空仓，改持黄金**
- 实测：r_score ≤ 0 的天数 126 → 109，正好少 17 天 ✓

**归因（致命）**：
- 17 天累计对数贡献 +0.0490，全期 nav 对数差 +0.0570 → **89% 的收益差来自这 17 天**
- 剔除最好的 1 天（2020-03-19 豆粕 +2.95%）→ 只剩 41%
- 剔除最好的 3 天 → 只剩 6%
- **剔除最好的 5 天 → -16%（变负）**
→ 典型路径依赖，不可采纳

**压仓层不是来源**（已排除）：关掉分位压仓+Boll 压仓后，纯 dual 层仍有 +0.48pp
（基线 22.26%/-25.79% vs 加国债 22.74%/-25.35%）→ 不是分位数参照系效应，就是那 17 天

### 「国债入 DEF 组」同样否决，且是确定的负贡献
- 国债 25 日动量为正占比 **72.1%**（黄金 57.0%、豆粕 57.2%、沪深300 53.0%、创业板50 47.9%）
- 但 25 日动量均值仅 **0.38%**、标准差 0.85%（黄金 1.07%/4.51%，创业板50 1.07%/10.66%）
- DEF 组是「无条件接盘」位置 → 国债靠高胜率抢到 153 天，**其中抢走黄金 116 天**
- 结果：CAGR -1.28pp（22.07% vs 23.35%），MaxDD 几乎无改善 → 确定变差

### 两组的真实语义（命名有误导性，务必记住）
| 组名 | 代码里的真实含义 | 入选门槛 |
|---|---|---|
| RISK_CODES | **趋势资产池**：只有最强者 25 日动量 > absolute_threshold(5%) 才买，满仓 | 必须赢过 5% 绝对门槛 |
| DEFENSIVE_CODES | **退路池**：只要 RISK 组最强者 ≤ 5%（含负数）就退到这里，**无条件接盘** | 只需是组内最强 |

- 低波动资产放 RISK 组 → 永远赢不了 5% 门槛 → 0 天被选中，只充当「是否空仓」的温度计
- 低波动资产放 DEF 组 → 靠高胜率频繁占坑 → 稀释防守质量
→ **结论：511260 两个组都不要加，保持现状（未启用）**

### 仍然成立的结论
- **MA250 趋势过滤依然有效**（窗口 60~300 单调改善、分段全改善、成本越高越划算）
  叠加方案改为：仅 MA250×0.5 → 23.08% / -17.45% / Calmar 1.32
- 黄金 518880 回撤压舱石结论不变（剔除后 MaxDD -24.20% → -32.08%）

### 【机制再更正】加国债 ≠ 废掉空仓，而是「满仓买入下跌中的防守资产」

**关键实验**：`cash_exit_threshold = -999`（判空永不触发）
- 业绩与基线**完全一致**：纯 dual 层 17.727 vs 17.727，完整层 20.149 vs 20.149
- 真实空仓天数（exposure==0）也完全相同：378 天 vs 378 天
- 原因：分支 4 `target_exposure = 1.0 if d_score > 0 else 0.0`，而触发
  both_weak_for_cash 的日子必然 d_score <= 0，所以本来就是 0 仓
→ **单纯「去掉切现金」对业绩零影响**

**加国债真正做的事（17 天实测）**：
- r_score 被国债的微小正动量顶成正值 → 走进**分支 3**
  （`elif r_score > 0 and d_asset notna`），该分支仓位 = `weak_trend_defensive_weight = 1.00`
  **完全不看 d_score 的符号**
- 17 天逐日：基线 exposure **0.00** → 加国债 **1.00**
- 这 17 天 DEF 组最强标的的 25 日动量**全部为负**：黄金 -0.11% ~ -2.51%、
  豆粕 -1.04%（2020-03-19）、红利低波 -0.54%（2021-08-19）
→ 加国债 = **在防守资产动量为负时满仓买入它**，本质是逆势抄底，无正期望
→ +0.5pp 只是 17 次抄底里赢了几把，机制上不可复现

**附带发现**：`cash_exit_threshold` 设为负数时是**死参数**（业绩零变化）。
只有设为正数才会扩大空仓范围、真正改变业绩（因为会拦截 r_score 小正的日子）。
`weak_trend_defensive_weight` 也是关键开关：分支 3 用它当仓位，不看防守资产动量好坏。
